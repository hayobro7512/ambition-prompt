# Answer key (judge only)
A correct solution: compare_versions(a, b) returns -1, 0 or 1. It strips whitespace and an optional v/V; compares any number of numeric release parts as numbers with missing parts as 0, so 1.10.0 is newer than 1.9.0, 1.2 == 1.2.0 and leading zeros are fine; applies SemVer prerelease ordering (prerelease older than release, numeric lower than alphanumeric, numeric compared as numbers, ASCII order, more identifiers newer); ignores build metadata after the first "+", including hyphens inside it; raises ValueError for malformed strings and TypeError for non-strings. Hidden tests (20) check each point.
Weak: string comparison; treating a prerelease as newer; returning something other than -1/0/1; accepting garbage silently; a third-party dependency; changing the signature.
