# Answer key (judge only)
The function must follow every requirement in the persona: int seconds; units w/d/h/m/s, case-insensitive; optional spaces between parts; each unit once, any order; decimals with halves-up rounding of the total; a bare number means seconds; clock format H:MM:SS and M:SS with fields below 60, not mixable with units; ValueError on empty, minus, unknown or repeated unit, malformed input; TypeError on non-strings. Correctness is measured by `hidden_tests/test_duration.py`. Weak: silently returning 0 or partial values for bad input; float return values; extra formats.
